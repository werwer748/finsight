# performance — 느린 쿼리·N+1

DB, 네트워크, 외부 API처럼 프로세스 밖으로 나가는 호출의 비용을 본다.

## 본다

- 쿼리와 API 호출의 횟수, 크기, 순서.

## 보지 않는다

- 프로세스 안의 계산 비용(알고리즘, 메모리) → cpu-perf

## 읽을 문서

- `docs/ADR.md`에서 변경이 닿는 것만: ADR-001(서버리스 실행 시간 제한), ADR-004와 ADR-010(가맹점 캐시), ADR-011(업로드 한 번에 Claude 요청 최대 100건)

## 체크 항목

1. 반복문 안에서 쿼리나 API 호출을 하나씩 보내는가? (N+1) 한 번에 묶을 수 있는가?
2. 캐시에 있는 가맹점을 다시 Claude에 보내는가? 같은 가맹점을 한 업로드 안에서 여러 번 보내는가?
3. 필요한 컬럼과 행만 조회하는가? `select *`, 기간 조건 없는 전체 조회, 조회한 뒤 코드에서 걸러 내기.
4. 서로 독립적인 호출을 차례로 `await`하는가?
5. 한 요청이 서버리스 실행 시간 제한을 넘길 만큼 길어질 수 있는가?
6. 마이그레이션이 바뀌었을 때: 자주 거는 조건(`user_id`, 날짜)에 인덱스가 있는가?
7. 여러 행을 한 건씩 insert하는가?
8. 정적으로 렌더링할 수 있는 페이지(랜딩, 샘플)가 동적 렌더링으로 바뀌었는가?
