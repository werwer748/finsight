# PRD: FinSight

## 목표
은행·카드사에서 내려받은 거래 내역 파일을 올리기만 하면, 어디에 얼마를 쓰는지 한눈에 보여준다.

## 사용자
국내 은행과 카드사를 쓰는 한국 개인 사용자. 가계부를 직접 쓰기는 번거롭지만 소비 흐름은 알고 싶은 사람.

## 핵심 기능
1. 파일 업로드: CSV, Excel(.xlsx, .xls) 형식의 거래 내역과 카드 명세서를 올린다.
2. 자동 분류: 가맹점명을 기준으로 거래를 카테고리로 나눈다.
3. 대시보드: 총 지출·수입, 카테고리별 지출 차트, 거래 내역 테이블.
4. Pro 분석: AI 인사이트 요약, 정기결제·구독 탐지, 월별 추이와 전월 대비 증감, 가맹점 TOP 랭킹.
5. 계정: 이메일과 비밀번호로 가입·로그인하고, 올린 내역은 계정에 저장된다.
6. 결제: Polar로 Pro 월간 구독을 결제한다.
7. 랜딩 페이지: 히어로와 가입 버튼, 가입 없이 가상 데이터로 대시보드를 보는 샘플 체험.

## 요금제
무료와 Pro 두 가지. Pro는 월간 구독만 있다.

| | 무료 | Pro |
|---|---|---|
| 업로드 | 월 1회 | 무제한 |
| 조회 기간 | 최근 1개월 | 전체 |
| 총 지출·수입, 카테고리 차트 | O | O |
| 거래 내역 테이블 | 보기만 | 검색·필터·카테고리 수정 |
| AI 인사이트 요약 | 잠금 카드 | O |
| 정기결제·구독 탐지 | 잠금 카드 | O |
| 월별 추이·전월 대비 증감 | 잠금 카드 | O |
| 가맹점 TOP 랭킹 | 잠금 카드 | O |

- 무료의 조회 기간 제한은 데이터를 지우지 않고 조회만 막는다. Pro로 올리면 과거 내역이 바로 열린다.
- 잠금 카드는 제목, 한 줄 설명, 업그레이드 버튼만 있는 단순 카드다.
- 무료 사용자에게는 AI 인사이트를 생성하지 않는다.

## 개발 단계
| Phase | 내용 |
|---|---|
| `0-skeleton` | 프로젝트 세팅, 랜딩(히어로), 로그인, 빈 대시보드, 배포 |
| `1-dashboard` | 파일 파싱, 가맹점 분류, DB 저장, 무료 범위 대시보드, 샘플 데이터 체험 |
| `2-pro` | Polar 결제, 플랜 권한 체크, Pro 전용 섹션과 잠금 카드 |
| `3-launch` | 실제 파일로 파서 보강, 실결제 전환, 약관·개인정보처리방침 |

현재 phase에 없는 기능은 미리 만들지 않는다.

## MVP 제외 사항
- HTML 파일 입력 (속이 HTML 표인 `.xls`는 Excel로 취급해 지원)
- 은행·카드사 계정 직접 연동, 자동 수집
- 소셜 로그인, 비밀번호 재설정 화면
- 연간 결제, 여러 단계의 유료 플랜
- 예산 설정과 알림
- 다크 모드, 다국어, 모바일 앱

## 디자인
- 밝고 깔끔한 핀테크풍. 흰 배경, 넉넉한 여백, 큰 숫자.
- 색상은 무채색 + 포인트 색 1가지. 라이트 모드만.
- 한국어 UI. 금액은 원화로 표기한다 (예: 1,234,000원).
